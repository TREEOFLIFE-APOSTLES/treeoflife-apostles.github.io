## 📡 Live HCN Dashboard

**[xrplove.github.io/hcn-network-dashboard](https://xrplove.github.io/hcn-network-dashboard/)**

The Hernandez Coordination Network dashboard, now with **live, read-only XRP Ledger data**: the latest ledger index, close time, base fee, reserve and transactions per ledger, updated every few seconds from public XRPL servers. No wallets, no keys, no signing.
Code: [xrplove/hcn-network-dashboard](https://github.com/xrplove/hcn-network-dashboard) · the original page: [xrplove/hcn-network](https://github.com/xrplove/hcn-network)

## 🛡️ Guardian MCP

**[xrplove/guardian-mcp](https://github.com/xrplove/guardian-mcp)**

A small, read-only [MCP](https://modelcontextprotocol.io) server that lets AI helpers look up live data from the XRP Ledger and the XRPL EVM sidechain: accounts, balances, tokens and ledger status. It never asks for keys or seeds. MIT licensed.
