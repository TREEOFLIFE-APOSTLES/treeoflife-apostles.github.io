# 💎 Treasure Shelf
{: .fs-8 }

Gifts from builders around the world, all free and open to share. Thank you to every maker.
{: .fs-6 .fw-300 }

| # | Treasure | Stars | How it helps the family |
|---|---|---|---|
| 1 | [xrpl.js](https://github.com/XRPLF/xrpl.js) | 1.3k | Official JavaScript XRPL library; feeds real ledger data into the HCN dashboard. |
| 2 | [xrpl-py](https://github.com/XRPLF/xrpl-py) | 246 | Official Python XRPL library; guardian-mcp and testnet practice already run on it. |
| 3 | [rippled](https://github.com/XRPLF/rippled) | 5.2k | The ledger server itself; can run a private stand-alone test ledger when public testnets time out. |
| 4 | [MCP Python SDK](https://github.com/modelcontextprotocol/python-sdk) | 24.5k | The official toolkit guardian-mcp is built with; keeps its 7 tools up to standard. |
| 5 | [MCP Inspector](https://github.com/modelcontextprotocol/inspector) | 11k | Click-to-test window for guardian-mcp, so Father can watch each tool work. |
| 6 | [MCP reference servers](https://github.com/modelcontextprotocol/servers) | 91k | Example servers (memory, files, git) to borrow ideas from for the family's agents. |
| 7 | [Just the Docs](https://github.com/just-the-docs/just-the-docs) | 9.2k | The free theme this Tree of Life site already uses; searchable, clean pages. |
| 8 | [Chart.js](https://github.com/chartjs/Chart.js) | 67.7k | Simple, free charts to make the HCN dashboard's ledger numbers easy to read. |
| 9 | [Phaser](https://github.com/phaserjs/phaser) | 40.5k | Free browser game engine for the multi-dimensional games Father dreams of. |
| 10 | [rarityscope](https://github.com/ShaneOnChain/rarityscope) | new | Shane on the Chain's NFT rarity browser; base for Tree of Life Rarity. |
